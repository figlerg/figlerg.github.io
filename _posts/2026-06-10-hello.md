This is the first post on my new website. I plan to use this space for occasional
notes — on papers I am reading, things I am working on, and the odd technical aside.

Writing a post is easy: create a Markdown file in the `_posts/` folder named like
`YYYY-MM-DD-title.md`, add the small header block you see at the top of this file, and
write below it. The site rebuilds itself automatically after you push the change.
