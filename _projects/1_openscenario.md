Scenario-based testing is a key technique for the verification &amp; validation of
autonomous driving functions. As part of my work at AIT, I develop an interpreter for a
domain-specific language based on **OpenSCENARIO 2.1**, used to describe and execute
test scenarios for autonomous vehicles.
